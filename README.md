## Objetivo

Essa é a entrega do trabalho da criação e implementação de uma ISA no Logisim da matéria de Projetos Digitais e Microprocessadores da UFPR 2026.

## Arquivos

Essa entrega possui arquivos de documetação localizados na pasta "docs", e arquivos de programas, bem como o compilador em Python para codificar o código dos programas do Assembly da ISA para um arquivo .hex para o processador no Logim executar, estando localizados na pasta "programas_teste". A entrega também possui um arquivo chamdo "processador.circ" tendo o circuito do processador para o Logisim executar, e um arquivo para carregar na ROM da Unidade de Processamento do circuito, chamado de "unidade_controle.hex".
